# @squinch/pack-sys

Generic system, infrastructure and shape icons from [Lucide](https://lucide.dev)
1.27.0 (200 icons) for [Squinch](https://squinch.cc/). Squinch installs this
pack for you: draw an icon as `sys/<id>`, and `squinch icons search --pack sys
<term>` finds one.
