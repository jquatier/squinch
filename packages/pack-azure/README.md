# @squinch/pack-azure

Microsoft's Azure architecture icons (release V24, 636 icons) for
[Squinch](https://squinch.cc/). Squinch installs this pack for you: draw an icon
as `azure/<id>`, and `squinch icons search --pack azure <term>` finds one.
