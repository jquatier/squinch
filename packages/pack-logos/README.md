# @squinch/pack-logos

Product and technology logos from [Simple Icons](https://simpleicons.org)
16.38.1 (283 logos) for [Squinch](https://squinch.cc/). Squinch installs this
pack for you: draw a logo as `logos/<id>`, and `squinch icons search --pack
logos <term>` finds one.
