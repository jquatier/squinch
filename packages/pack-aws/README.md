# @squinch/pack-aws

Amazon's AWS Architecture Icons (the 30 April 2026 release, 316 icons) for
[Squinch](https://squinch.cc/). Squinch installs this pack for you: draw an icon
as `aws/<id>`, and `squinch icons search --pack aws <term>` finds one.
