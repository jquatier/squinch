Privacy

No accounts. No cookies.

Squinch collects nothing about you. Here is everything that leaves your machine, and where it goes. Last updated 27 November 2026.

This website

Every page except the playground counts visits with Cloudflare Web Analytics. It uses no cookies and keeps no identifiers: it records the page, the site that linked you here, your browser, your country and how fast the page loaded.

The site is hosted on GitHub Pages, which logs visitors' IP addresses for security; see GitHub's privacy statement.

The playground

No analytics. What you write stays in your browser's local storage. A share link carries the diagram after the #, which browsers never send to a server.

The CLI, plugin and extension

The CLI checks the npm registry for a newer version at most once a day. It skips the check in CI, and SQUINCH_NO_UPDATE_CHECK=1 turns it off. Nothing else is sent anywhere: not your diagrams, not how you use it. The plugin and the VS Code extension send nothing at all.

Questions? Open an issue. Every change to this page is in its history.
