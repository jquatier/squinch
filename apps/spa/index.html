Your coding agent already knows the architecture.
Now it can draw it.

Describe the system in a paragraph. Squinch renders it precisely — layout you steer without placing a box, vendor-accurate icons, and diagrams you can zoom into, from the whole landscape down to one service's internals. It ships as a skill for the agent you already use — one install and it speaks the language.

Multiple altitudes, one model

Zoom into any system

The altitudes are derived, never drawn twice: a collapsed system is a card previewing what's inside, and opening it shows the internals while the neighbours it talks to stay on screen as muted context. Edges that cross the boundary re-anchor themselves. One model, every altitude — no second diagram to maintain, so nothing can drift.

Motion carries meaning

Packets down a queue, a slow dashed archive job, a comet on the final push — cadence you can read, from CSS keyframes and never script.

Real deployment boundaries

VPCs, subnets, cloud and on-prem zones: nested, tinted by kind, labelled where you'd expect them.

1,302 vendor icons

AWS, Azure, Kubernetes and the products around them — Kafka, Postgres, Datadog — not grey boxes with labels inside.

Deterministic, not best-effort

Diagrams you can commit

  • The same bytes on every machine

    One source, one SVG — identical on macOS, Linux and Windows. Your diff shows what you changed, never what your laptop did.

  • The font ships with the renderer

    Text is measured against a bundled metrics table, never against the machine it runs on. Nothing reflows because someone else installed a different font.

  • No network. No telemetry.

    Renders offline and tells nobody. No update pings, no account, no icon fetched at render time.

  • Rigorously tested, agents included

    Independent cold agents get a prose brief, the skill and the CLI — nothing else. Every diagram they write is committed and re-scored by CI.
