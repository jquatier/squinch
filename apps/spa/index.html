Now it can draw it. Describe the system in a paragraph and Squinch renders it precisely: real layout control, vendor-accurate icons, and diagrams you can zoom into — from the whole landscape down to one service's internals.

Zoom into any system

Every system opens into its own internals with one click, and zooms back out just as easily — landscape, service, and everything between are views of one model, not separate diagrams you have to keep in sync.

Everything included

  • 1,302 vendor icons

    AWS, Azure, Kubernetes and product logos, not grey boxes with labels on them.

  • Layout you can overrule

    Good diagrams with no hints at all; disagree, and you steer it with relative hints, never pixel coordinates.

  • One model, many diagrams

    A landscape view, a per-service view, a filtered view for an audit, all from the same source, so they can't disagree with each other.

  • Real deployment boundaries

    VPCs, subnets, cloud and on-prem zones, nested, tinted by kind, labelled where you'd expect.

  • Numbered request flows

    Declare a flow and its steps are numbered along the edges, walkable one hop at a time.

  • SVG, PNG, or HTML export

    The HTML carries every view with click-to-zoom and presentation mode, no server, no internet, nothing to install.

  • A real VS Code extension

    Autocomplete, live errors with one-click fixes, and a preview that updates as you type.

  • Reviewable in a PR

    The source is a handful of readable lines, and squinch diff spells out exactly what changed.

  • Generated in CI

    A ready-made GitHub Action re-renders on every push, so the picture in your docs is never stale.

  • Light and dark

    Dark is designed, not inverted, one file can carry both and switch with the reader's system theme.
